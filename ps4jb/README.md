# PS4 12.50–13.00 exploit chain

Bundled SlopKit WebKit + **poops** kernel chain for PS4 12.50, 12.52 and 13.00,
plus the Lapse chain for 11.00–12.02. The chain requires the AppCache manifest
so payload and kernel patch files are loaded from the offline cache during the
timing-sensitive race.

Chain code and payload come from the public `psx8/psx8.github.io` 13.00 host
(originally rawgame4 / PlayStation Pulse). Credits belong to their authors.

This is separate from the site's `engine/` (ufm42/wobkot), which only supports
PS4 up to 12.02.
